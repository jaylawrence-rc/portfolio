# Jay's publications and design products

The Portfolio Journal and Jay's Lab are distinct publications by Jay Lawrence Dimaano. Ship Onwards is a separate product demonstrated in Jay's Lab. Related content has one publication home.

## Language

**Portfolio Journal**:
The existing collection of essays published with the portfolio. It remains a separate publication from Jay's Lab.

**Jay's Lab**:
Jay's independent publication for curated technical learning, personal standards, and AI agent skills.
_Avoid_: Tech Journal

**Ship Onwards**:
Jay's separate product for solo founders seeking a curated finished product UI direction with a coding agent. Its prototype site is the first Showcase Site in Jay's Lab, and it is intended to become the storefront after validation.

**Learning Note**:
A published account of what Jay is investigating or has learned about a technical topic. It explains the current understanding without presenting every conclusion as a rule.

**Architecture Explorer**:
An interactive part of a Learning Note that lets readers trace data and decisions across a system's trust boundaries.

**Standard**:
Jay's explicit preferred practice or pattern for engineering, product design, or user experience. It states a judgment that can guide future work.

**Agent Skill**:
A packaged, repeatable workflow with instructions, templates, and checks that guides an AI coding agent through a specific kind of work.

**Skill Listing**:
A public description of an Agent Skill that helps a reader judge its purpose and fit.

**Standard Bundle**:
A curated set of Standards for a product or build context. It gives a coding agent a coherent set of Jay's defaults without changing the individual Standards' authority.

**Draft**:
An unpublished entry kept outside the public publication until it is approved for release.

**Experiment**:
An interactive exploration of an interface, animation, or technical idea published in Jay's Lab.

**Showcase**:
Jay's Lab gallery of finished, navigable UI results made with the Design Skill and explained through case studies.

**Design Skill**:
An Agent Skill that guides a coding agent to create or refine a coherent design system and user interface in a web project.

**Design Profile**:
A versioned, validated set of visual preferences that a Design Skill derives from a repository or imports from the Lab Configurator.

**Product Pattern**:
A curated structure for a product page or user flow, including its purpose, content hierarchy, interaction states, and applicability. It informs a Design Skill's proposed direction.

**Configurator**:
An interactive Lab tool for adjusting a Design Profile and previewing the resulting visual choices.

**Showcase Site**:
A navigable example website created or refined with a Design Skill to make its result inspectable.

**Retrofit Case Study**:
A documented before-and-after application of a Design Skill to an existing website or app.
