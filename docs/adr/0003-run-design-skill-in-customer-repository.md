# Run the Design Skill in the customer's repository

Jay's Lab demonstrates the Design Skill through navigable Showcase Sites and a public Configurator, while the product sold to customers is an installable agent skill with configuration and examples. A customer's coding agent applies it inside their own Next.js or React repository, including an existing app. The skill can infer a Design Profile from that repository or use an exported Lab profile as an optional override. It works with existing styling conventions where tested. This lets the workflow inspect real components and conventions without making the Lab a hosted source-code upload or live generation service; the Lab exports a Design Profile rather than taking custody of customer code. Demo source code may be public, while the paid workflow files remain private.
